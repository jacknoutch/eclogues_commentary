# eclogues_commentary
A Digital Commentary of Vergil's Eclogues

## Resources

- Text is from Perseus; I obtained it via the [Scaife viewer](https://scaife.perseus.org/reader/urn:cts:latinLit:phi0690.phi001.perseus-lat2:1).
- Lemmatisation and morphological analysis is from Lasciva Roma's [Latin Lemmatized Texts repository](https://github.com/lascivaroma/latin-lemmatized-texts).
- Glosses are derived from Logeion's [shortdefs repository](https://github.com/helmadik/shortdefs/tree/master).
- Principal parts are used from Pellegrini, M. & Passarotti, M. & Mambrini, F. & Moretti, G. 2025. PrinParLat version 2. Online resource.

Whilst I rely on these excellent works, all errors remain my own.
